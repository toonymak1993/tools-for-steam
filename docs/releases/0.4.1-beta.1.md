# Tools for Steam 0.4.1-beta.1

This beta adds two major controller-first experiences to Steam: **OmniLibrary** for external game libraries and the new **Wishlist Shop** for comparing game prices without leaving Big Picture.

## Highlights

- Added the Wishlist Shop with direct regional price comparisons across Steam, GOG, Xbox, Epic Games, and exact Instant Gaming matches.
- Added OmniLibrary as an alternative to Store Sync, with dedicated Xbox, optional Xbox Cloud, Epic, and GOG tabs inside Steam Library.
- Added download, progress, play, and safe uninstall flows for OmniLibrary-managed games.
- Download pages now show a live Steam-style phase panel, animated native action icon, progress, transfer speed, processing/disk throughput, and remaining time where the provider exposes those values.
- Reworked library-tab navigation so LB/RB and D-pad traversal remain consistent with every supported combination of enabled stores.
- Reduced background CPU, memory, network, shortcut, and artwork work through cached snapshots and incremental five-minute store deltas.

## Wishlist Shop

- Added a permanent Wishlist entry that opens a full-screen, controller-native shop inside Steam.
- Combines the public Steam wishlist with a separate local TFS wishlist, allowing games outside Steam to be saved as well.
- Added Discover, Search, Wishlist, Price Alerts, and Settings sections.
- Compares available prices from the selected regional Steam, GOG, Xbox, and Epic Games storefronts.
- Shows Instant Gaming only for an exact, available PC match with a readable regional price.
- Added direct product-page links, best-price actions, sale discovery, regional currency display, and USD/EUR comparison options.
- Added configurable price alerts with background checks, notifications, and local price history.
- Keeps the latest successful price cache visible when an individual storefront is temporarily unavailable.

## OmniLibrary

### Store integration

- Added individually configurable Xbox, Xbox Cloud, Epic Games, and GOG providers.
- A store tab appears only after that provider is enabled, connected, synchronized, and prepared.
- OmniLibrary and Store Sync are mutually exclusive so they cannot create competing entries or background jobs.
- Disabling OmniLibrary removes its tabs, input hooks, managed game-page actions, and background checks.

### Native Steam experience

- External libraries appear as dedicated tabs instead of being grouped into Non-Steam.
- Added one controller-native Download Center at the top of OmniLibrary for concurrent Xbox, Epic, and GOG transfers.
- Each transfer exposes its phase, percentage, size, speed, remaining time, and store-specific status without rebuilding the full library.
- Managed library tiles switch to an animated download indicator immediately after the native Steam action is selected.
- Epic and GOG downloads can be paused, resumed from checkpoints, canceled with a second confirmation, and cleaned up independently. Xbox opens the exact native product page for controls owned by Windows.
- LB/RB and d-pad navigation dynamically follow the currently available native and OmniLibrary tabs.
- Entering and leaving a managed game page restores the correct store tab and selection.
- Compact icons distinguish installed, downloadable, and cloud-playable games.
- Only OmniLibrary-managed entries may change Steam's original action between Download, progress, Retry Download, and Play. Native Steam games remain untouched.
- Installed games use Steam's normal running-game lifecycle, including Resume and Stop while the game process is active.

### Xbox and Xbox Cloud

- Uses the signed-in Xbox app session, PC Game Pass catalog data, and local Xbox installation manifests.
- Added an optional, separate Xbox Cloud tab that does not mix cloud-only games into the local Xbox library.
- Added best-effort direct installation, live progress reconciliation, completion detection, and launch detection.
- Falls back safely to the exact Xbox product page when Windows does not grant the private install capability; TFS never automates a purchase or confirmation.
- Xbox uninstall remains user-controlled through the exact product page and is reconciled automatically after removal.

### Epic Games

- Added isolated Epic sign-in inside Steam.
- Added library synchronization, background delta checks, downloads, progress, launch, and managed uninstall through Legendary.
- Large Epic downloads now keep absolute progress across resumes, show current transfer speed on Steam's native action, and automatically resume transient failures with bounded backoff.
- Added configurable Epic worker count and connection timeout settings, with safe defaults of 16 workers and 60 seconds.
- Epic download telemetry records network, decompression, disk-write, and disk-read throughput for diagnosing CDN or storage bottlenecks.
- Interrupted Epic transfers recover from their Legendary checkpoint after TFS/Windows restarts; durable status writes retain a backup across unexpected power loss.
- Automatic reconnect attempts remain visible and `Retry Download` appears only after the helper has reported a terminal error or all bounded recovery attempts are exhausted.
- TFS prevents system sleep while an OmniLibrary download is active, while leaving the user's normal display timeout unchanged.
- A preflight capacity check keeps a safety reserve so very large installations cannot silently fill the Windows drive.
- Legendary is pinned, SHA-256 verified, and downloaded from its official upstream release when first required.
- Epic can coexist with the official Epic Games Launcher without sharing or overwriting its session.

### GOG

- Added isolated GOG sign-in, library synchronization, downloads, launch, and managed uninstall through heroic-gogdl.
- heroic-gogdl is pinned, SHA-256 verified, and downloaded from its official upstream release when first required.
- Added GOG publisher-setup and redistributable handling for games that need DirectX, Visual C++ runtimes, registry setup, or compatibility flags after their files are downloaded.
- The complete GOG setup chain now runs through one validated elevated TFS worker, reducing first-install UAC prompts to one setup approval.
- Fixed older games selecting a launcher task instead of the actual game executable.
- Fixed deleted GOG games being impossible to download again because of a stale gogdl installation manifest.
- Shared GOG runtimes are cached, while per-game setup is version-bound and repeated only when the installed build changes.
- GOG transfers preserve partial files, retry transient interruptions with bounded backoff, preflight available disk capacity, and resume after TFS or Windows restarts.
- Added an atomic per-game GOG transaction journal so interrupted downloads, verification, and Windows setup resume from the correct phase.
- Added batched update detection, optional DLC installation, configurable workers and timeout, optional Galaxy launch mode, and controller-accessible **Verify & Repair** for OmniLibrary-managed installs.
- GOG installation changes made by Galaxy are reconciled from one cached registry snapshot; external Galaxy-owned directories remain protected from managed repair or deletion.

## Performance and reliability

- Store libraries use lightweight five-minute catalog checks and process only added, removed, or changed games.
- Initial artwork preparation remains asynchronous; later checks repair only missing or changed assets.
- Artwork prefers Steam's public images and falls back to SteamGridDB or the connected store artwork.
- Cached Quick Access and OmniLibrary state avoids repeatedly rebuilding large libraries while navigating Steam.
- Download and installation monitoring uses adaptive polling and event data instead of constant full-library scans.
- Live transfer revisions no longer invalidate and rebuild the complete OmniLibrary catalog, removing delayed Download Center discovery on large libraries.
- Active Xbox, Epic, and GOG transfers survive Steam, TFS, and Windows restarts and continue even if the OmniLibrary UI is disabled afterward.
- Recovery and partial-file cleanup are isolated per game, so one failed entry cannot block another provider or concurrent download.
- Improved TFS startup, splash-screen completion, Quick Access loading, and return navigation from game pages.
- Reduced unnecessary Steam UI reinjection and background work when plugins or stores are disabled.

## Fixed

- Fixed LB/RB navigation becoming trapped between two external store tabs.
- Fixed tabs appearing only after the first bumper press or pushing the user back to another store.
- Fixed Xbox Cloud automatically returning to the Xbox tab.
- Fixed d-pad navigation focusing a tab without activating it.
- Fixed managed badges and labels being invisible, localized inconsistently, or applied to native Steam games.
- Fixed Xbox download progress disappearing too early while the Xbox app continued downloading.
- Fixed completed Xbox installs requiring an unnecessary Xbox app restart before Play became available.
- Fixed completed installs and uninstalls taking too long to update Play, Download, and library badges.
- Fixed an older in-flight library summary briefly changing a completed game back to Download or removing it from Installed.
- Xbox removal now uses a guarded per-game path/package probe; Epic and GOG publish their managed worker completion. All providers trigger one compact installed-state delta refresh without rebuilding catalogs or artwork.
- Fixed plugin UI and tab changes remaining active after OmniLibrary was disabled.
- Fixed expensive full catalog and artwork rebuilds after a single store-library change.

## Security and compatibility

- Epic and GOG credentials stay inside isolated OmniLibrary data directories and are not copied from the official launchers.
- Store helpers are version-pinned and verified before execution.
- Partial download cleanup accepts only paths strictly contained below the configured provider root and refuses filesystem reparse points.
- Elevated GOG setup accepts only a validated managed installation, exact game identifier, matching authenticated manifest signature, and paths contained by TFS-owned store directories.
- Store disconnect removes the isolated account session, cached account data, and managed shortcuts without deleting installed games.
- Steam Big Picture UI patches remain sensitive to future Steam client changes; store data and installed game files remain intact if a visual patch cannot attach.
