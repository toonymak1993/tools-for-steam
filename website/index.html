Launch flow

From power-on to attached Big Picture in one readable sequence.

The idea is simple: the PC starts, TFS comes up first, the Windows background host is ready, and Big Picture opens with Tools for Steam already attached.

04 Cleanup

Desktop icons and taskbar are hidden

Before the final handoff, TFS clears the regular Windows desktop so Big Picture becomes the only visible front layer.

The desktop and taskbar stay hidden until Big Picture is closed again.
05 Attach
