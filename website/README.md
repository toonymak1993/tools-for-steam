# Website Preview

This landing page is intentionally kept fully static so you can refine it locally before deciding where to deploy it.

## Files

- `index.html`
- `styles.css`
- `app.js`

## Open locally

- Double-click `website/index.html`
- or from PowerShell:

```powershell
Start-Process .\website\index.html
```

## Deploy later

The structure is simple on purpose, so the site can move to a static host like Cloudflare Pages, Vercel, or GitHub Pages without a rebuild of the whole project.
